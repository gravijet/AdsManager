Integration

So bindest du das Werbe-Widget auf einer Website ein.

1. iFrame einbetten

Ersetze SITE_KEY mit dem Key der jeweiligen Website (siehe „Websites"-Tab).

<iframe
  src="https://example.invalid/?site=SITE_KEY"
  width="360" height="280"
  style="border:0;"
  allow="autoplay"
></iframe>

2. Auf die Belohnung reagieren

Das Widget sendet postMessage-Events an die einbettende Seite.

window.addEventListener("message", (event) => {
  if (event.data?.type === "werbung:reward") {
    // Belohnung freischalten. event.data.adId kann null sein
    // (kein Ad verfügbar, Fallback "sofort gewähren").
  }
  if (event.data?.type === "werbung:click") {
    // Nur bei Klick-Aktion "postmessage": event.data.payload
  }
  if (event.data?.type === "werbung:ready") {
    // Widget ist geladen.
  }
});

// Optional: Widget von außen zurücksetzen (z.B. neuer Versuch)
iframeEl.contentWindow.postMessage({ type: "werbung:reset" }, "*");

Hinweise

  • Klick-Aktion „Seite oben ersetzen" funktioniert nur, wenn der iFrame kein sandbox-Attribut ohne allow-top-navigation hat.
  • Frequenzbegrenzung läuft über localStorage im iFrame — private Browserfenster oder deaktiviertes Storage setzen sie außer Kraft.
  • Ohne ?site=-Parameter erhält der Betrachter Anzeigen aus dem globalen Pool (keine Website-spezifischen Regeln, keine site-exklusiven Anzeigen).
